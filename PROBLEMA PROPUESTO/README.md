# Taller MongoDB - Problema Propuesto (SENA)

Este repositorio contiene la solución al problema propuesto de la capacitación de MongoDB, simulando el sistema de inventario de una concesionaria de vehículos.

## Operaciones Implementadas
- **Creación:** Base de datos `ProblemaPropuesto` y colección `carros`.
- **Inserción:** Uso de `insertOne` y `insertMany`.
- **Consultas:** Filtros básicos, operadores de comparación (`$ne`, `$gte`, `$lte`) y consultas combinadas.
- **Actualización y Eliminación:** Uso de `updateOne` y `deleteOne`.

## Cómo ejecutar
1. Abrir la terminal y ejecutar `mongosh`.
2. Copiar y pegar el contenido de cada archivo `.js` en la shell de MongoDB en el orden numérico.
