# Ejercicios y Prácticas de MongoDB

Este repositorio contiene una serie de scripts, guías y soluciones prácticas para el aprendizaje y dominio de **MongoDB** (base de datos NoSQL). 

## 📂 Contenido del Repositorio

El proyecto está dividido en los siguientes bloques:

1. **Fundamentos y Operaciones Básicas:**
   - `1. creacion de bases datos NoSQL-MONGODB.js`: Creación de bases de datos y colecciones.
   - `2. CREACIÓN DE ÍNDICES PARA OPTIMIZACIÓN.js`: Creación de índices para mejorar el rendimiento.
   - `3. INSERCIÓN DE DATOS DE PRUEBA.js`: Scripts para poblar la base de datos.
   - `4. CONSULTAS DE EXTRACCIÓN DE INFORMACIÓN.js`: Consultas básicas y avanzadas (find, aggregate).
   - `5. SCRIPTS DE MANTENIMIENTO Y ADMINISTRACIÓN.js`: Respaldos, eliminación y mantenimiento.
   - `6. CONEXIÓN CON PYTHON (FLASK) - EJEMPLO PRÁCTICOpy`: Ejemplo de integración con Python.
   - `7. GUION DE PRUEBAS Y VERIFICACIÓN.js`: Scripts de validación.

2. **Guía Práctica (Fútbol/Torneo):**
   - Carpeta `GUIA PRACTICA`: Contiene un paso a paso (`.sh` y `.js`) para crear un entorno, insertar equipos y partidos, y realizar consultas.

3. **Problema Propuesto (Taller):**
   - Carpeta `PROBLEMA PROPUESTO`: Solución a un taller de consultas, actualización y creación de bases de datos.

## 🛠️ Requisitos Previos

Para ejecutar estos scripts, necesitas tener instalado:
- [MongoDB Community Server](https://www.mongodb.com/try/download/community)
- [MongoDB Shell (mongosh)](https://www.mongodb.com/try/download/shell)
- (Opcional) Node.js y Python (Flask) para los ejemplos de conexión.

## 🚀 Cómo ejecutar los scripts

Puedes ejecutar los archivos `.js` directamente desde la consola de MongoDB (`mongosh`). Por ejemplo:

```bash
mongosh < "1. creacion de bases datos NoSQL-MONGODB.js"
